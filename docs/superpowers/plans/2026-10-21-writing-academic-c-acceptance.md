## 验收结论

学术 C 的主要工作路径已在从 D 盘项目 `server.js` 提供的浏览器开发版中实际走通：论文创建、目标要求、章节单元、证据/要求/风格材料分流、五类任务提示词、模拟结果回带、问题复核和重载恢复均成功。工作区备份保留学术目标、资料库备份排除写作记录也通过自动化验证。

## 应用操作与结果

| 场景 | 观察结果 |
|---|---|
| 学位论文创建 | 直接创建 `academic-paper` 工作区，无普通文章确认；研究目标、读者、学科和研究范围显示在工作台。 |
| 目标要求 | 录入目标学校、学位层级、引用格式及一条机构要求；模拟来源保持“未核验”，提示词保留其版本和来源状态。 |
| 章节 | 新建“第二章 研究方法”，设置章节目标和完成标准；生成任务时章节名称与职责进入提示词。 |
| 材料用途 | 关联一条研究证据、一条目标要求和一条风格样本。前两项只用于本章节；风格只生成形式特征，样本原句不进入提示词。 |
| 学术任务 | 研究规划、提纲、章节起草、诊断、定向改稿均生成独立版本，记录对应任务类型及 `builtin-academic-paper` v1 快照。诊断要求位置、依据和待核验边界；改稿保留结论强度与复核要求。 |
| 结果与问题复核 | 带回两轮明确标注为模拟的外部结果；手动记录候选问题，并关联后续轮次后标为“复核通过”。没有调用真实模型。 |
| 保存与重载 | 开启本机保存后 3 轮均显示已保存；重载页面后目标、章节、3 份材料、提示词版本、问题状态和复核轮次均恢复。 |
| 窄屏与键盘 | 390×844 CSS 像素下页面宽度为 375，无横向溢出；从章节范围选择框按 Tab 可到达章节标题输入框。 |
| 控制台 | 当前检查窗口没有 console error 或 warning。 |
| 备份 | 学术目标完整工作区备份往返保留；资料库备份不包含 `writingArticles`。凭证与绝对路径清理有存储/备份回归覆盖。 |
