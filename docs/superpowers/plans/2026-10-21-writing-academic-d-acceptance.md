| 场景 | 操作与观察结果 |
|---|---|
| 多来源论断 | 从学术文献库登记两条合成摘录并关联同一论断，分别标为支持和相冲突；实际提示词保留两条来源各自对应的摘录、位置与关系，覆盖状态显示存在相反来源。 |
| 审稿实际修改与未解决项 | 分别建立两轮意见；第一条记录实际修改摘要、位置和修改后摘录，第二条保留未解决状态。单独选择第二条生成提示词时，提示词如实呈现未解决状态，不声称已修改。 |
| 缺失的投稿要求 | 添加缺少原文和来源位置的要求卡，界面仍标为未核对；所选清单项生成提示词时列出来源状态、缺失的用户记录证据和待核对边界，不显示自动合规结论。 |
| 工作区备份替换 | 通过应用导出完整工作区 JSON；导出后创建第二个已保存的学术项目，再从应用导入并选择替换。原项目恢复，后建项目移除，状态提示“导入成功：已替换”。 |
| 工作区备份合并 | 另一个隔离上下文中先导出并删除备份项目，再创建不同 ID 的当前项目，导入备份选择合并；备份项目恢复且当前项目保留，状态提示“导入成功：新增 1 条”。 |
