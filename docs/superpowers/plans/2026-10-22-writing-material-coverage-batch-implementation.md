# 写作资料库与授权目录全范围批处理实施计划

对应设计：`docs/superpowers/specs/2026-10-20-writing-domain-expansion-design.md` 第 9.3、13、17.1 节（D09、D11、A08、A10、A11、A15）。

## 目标

在统一写作工作台中，让用户可以确认资料库/授权目录的集合范围与筛选条件，再逐批交给外部 AI 处理并记录实际覆盖情况。清楚区分发现、已选、待处理、用户确认已处理、排除和失败材料；范围变化、重试、刷新和恢复不得造成漏计或重复计数。现有综述专用筛选批次继续保留自己的研究协议，不用其结果代替通用材料覆盖。

本功能只生成可复制的分批提示词、保存用户确认的批次状态和覆盖报告；不在应用内自动发送正文、不自动读取整库全文，也不把“已复制提示词”当作外部 AI 已处理。

## 实施约束

- 先检查当前工作区及 `writing-workbench` 的 schema、材料选择、授权目录搜索、存储和备份实现；保留所有既有改动。
- 沿用原生 JavaScript/DOM、现有白名单 schema、项目保存开关和备份流程；不增加数据库、依赖或第二套任务引擎。
- 按阶段先写失败测试；阶段完成后运行对应定向测试、`pnpm check` 与 `git diff --check`。
- 以固定合成资料在 D 盘开发版验收范围预览、批次生成、回带/确认、失败/排除、重试去重、保存恢复及覆盖报告；不调用真实模型，不做真机测试，不提交。

## 阶段 0：基线和数据来源

- [x] 核实 `knowledgeEntries` 与授权目录索引可提供的稳定 ID、来源版本/指纹、相对位置、内容状态、筛选条件、访问失败状态及现有数量上限。
- [x] 区分“搜索命中集合”和“用户确认的全量范围”；授权目录索引现在逐项报告受支持/不支持/超限/二进制/编码不支持/不可用/安全排除，并对遍历失败标记范围不完整。
- [x] 复用现有综述批次接口作为行为参考，记录不可复用之处；不更改学术综述协议。
- [x] 确认写作项目保存开关和工作区备份白名单可持久化覆盖快照、批次和来源版本，不写入目录绝对路径或未选择的附件全文。

**退出条件：** 能从现有数据源准确列出已确认范围内的所有候选项，并保留稳定来源身份；若某来源不能穷举，UI 必须标记范围不完整，禁止显示 100% 覆盖。

## 阶段 1：覆盖状态 schema 与批次纯逻辑

**范围：** `prototype/writing-workbench-schema.js`、新增 `prototype/writing-material-coverage.js`、对应 schema/新模块测试及备份测试。

- [x] 先为覆盖范围快照、筛选条件、稳定来源 ID/版本、条目状态、排除/失败原因、批次序号、提示词版本 ID、用户确认依据和统计不变量编写失败测试。
- [x] 仅保存白名单字段；拒绝凭证、绝对路径、解析全文、未知状态和悬空引用，并校验批次与条目状态双向一致。
- [x] 实现确定性的批次切分与统计：每个范围条目只能计入一个当前状态；重复回带或重试不重复计数；来源版本变化会使旧覆盖标记失效并要求复核。
- [x] `prompt-copied`、`result-pasted` 与“用户确认外部已处理”分别记录；只有显式确认后才计入完成，确认需关联批次和结果/依据说明。
- [x] 运行 schema、模块和备份相关定向测试。

**退出条件：** 范围、重复、变更版本、失败重试、退出/暂停和备份恢复均有确定状态；旧写作数据兼容。

## 阶段 2：协调器与保存恢复

**范围：** `prototype/writing-workbench-coordinator.js`、`prototype/storage.js`、相关测试。

- [x] 新增确认范围、生成下一批、关联提示词版本、记录回带结果、显式确认完成、排除、失败和重试操作。
- [x] 每次生成提示词只包含当前批次已选摘录和来源清单；完整范围清单与当前批次清楚区分。
- [x] 生成授权目录批次前重新检查授权状态和来源指纹；来源消失/变化不会被算作完成。
- [x] 覆盖快照遵循文章保存开关；开启保存时写入确认状态，存储和工作区备份往返保留批次、版本和依据。重新确认范围时保留最近十个旧范围及逐项/批次历史。
- [x] 运行协调器、schema、存储和工作区备份专项测试。

**退出条件：** 全范围计数可从逐项状态重算；重试、改范围和恢复均不产生重复完成或丢失记录。

## 阶段 3：写作工作台 UI

**范围：** `prototype/writing-workbench-ui.js`、必要 HTML/CSS 与 DOM 测试。

- [x] 增加“范围批处理”：可预览完整资料库或授权目录；支持按相对路径筛选子目录、逐项纳入/排除，显示不可用项和范围完整性，再由用户确认范围。
- [x] 展示每项材料的稳定来源、相对位置/版本、待处理/已处理/排除/失败状态和理由；不把检索相关度前 N 条显示为全量覆盖。
- [x] 允许生成当前批次提示词、复制、回带外部结果、显式确认已处理、排除、记录失败并重试；复制状态与处理确认分别记录。
- [x] 展示发现、待处理、处理中、已带回、完成、排除、失败数量和逐项清单；范围不完整时不显示覆盖率。
- [x] 主要控件具备可访问名称并使用原生键盘交互；保留现有三份普通轮次材料上限。
- [x] 运行写作 UI、协调器与提示词专项测试。

**退出条件：** 代表用户可仅用可见控件完成范围确认到覆盖复核；当前批次内容与屏幕预览/复制文本一致。

## 暂不纳入

不实现整库静默上传、无限量全文解析、自动事实核验或自动确认外部 AI 已处理；不把模型/字符估算当作准确 token 计量；不把综述筛选覆盖数据套用为其他写作材料完成状态。
