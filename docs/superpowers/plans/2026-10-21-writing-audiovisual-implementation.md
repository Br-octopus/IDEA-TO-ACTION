# 写作工作台视听与社媒实施计划

对应规格：`docs/superpowers/specs/2026-10-21-writing-audiovisual-spec.md`
上位设计：`docs/superpowers/specs/2026-10-20-writing-domain-expansion-design.md` 第 5—17 节
依赖：共用核心 A/B/C、材料入口与来源、基础包、学术 A—D 已完成阶段验收
执行方式：按任务耦合、并行收益和交接/集成成本选择当前代理或子智能体；按阶段做规格核对、代码复审、定向验证和应用验收。
当前状态（2026-10-21）：未完成。虽有五类领域包/schema 的部分代码，计划要求的独立完整路径、结果回填、保存刷新、键盘/窄屏和应用验收均无阶段记录；本文件创建时的“尚未实施”仅描述当时状态。

## 目标

在现有本地写作工作台中交付社媒图文、短视频、口播、播客、演讲五类专属提示词任务。继续使用现有项目/轮次、专业基础包、材料/来源、历史、保存和备份机制；每条任务可在没有模型配置时完成提示词生成、编辑/复制、手工带回结果及本地复核。平台规则和事实均可追溯，但不宣称应用或模型已经核验其正确性或平台合规性。

## 实施约束

- 先复核实际工作区和未提交改动；只修改本阶段必要文件，不覆盖无关改动。
- 继续沿用原生 JavaScript、DOM、Electron、现有 schema/coordinator/UI 和 `node:test`。只有职责确实不同才新增小模块；不引入通用插件框架、服务端平台适配、平台 API 或新依赖。
- 数据扩展走现有白名单 schema、存储和工作区备份；旧文章、学术数据与历史保持可读。
- 各项先补失败测试，再做最小实现；每个任务完成后运行对应专项测试，再进入下一项。不得用提示词快照测试替代真实界面路径。
- 隔离数据验收。默认不请求模型、不联网查询平台规则；如测试观察到未预期请求立即停止该路径并定位来源。
- 本计划不把当前阶段文档草案视为实现完成。实现期间另建应用验收记录，完成后再更新上位蓝图的阶段状态。
