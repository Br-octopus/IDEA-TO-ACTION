## 应用操作与结果

| 场景 | 观察结果 |
|---|---|
| 叙述性综述 | 在 Electron 中创建项目、加入题录快照，逐字段确认模拟提取值；确认值写入项目。 |
| 系统综述双人筛选 | 审阅者一纳入、审阅者二独立排除；审阅者二的模型候选不能被接受或覆盖人工决定；分歧经人工裁定后纳入。 |
| 全文未获取 | 系统综述记录“馆藏未能提供全文”；覆盖显示 `fullTextNotRetrieved=1`、`complete=false`。 |
| 范围综述 | Electron 中创建并保存范围综述，固定一条题录快照，记录题名/摘要纳入和全文无法获取；`complete=false`，符合未完成研究不得显示完成的要求。 |
| 重载恢复 | Electron 页面重载后，叙述、范围、系统三个已保存项目及各自一条记录仍可读取。 |
| 方法与边界 | UI 展示 PRISMA 2020、PRISMA-ScR、PRISMA-S、Cochrane Handbook、JBI 来源及适用边界；提示词明确标识题录/摘录范围，不声称读过未提供的全文。 |
| 窄屏与键盘 | 隔离浏览器设为 390×844 CSS 像素，`document.documentElement.scrollWidth=375`；Tab 可聚焦项目标题输入框。控制台没有 warning/error。 |
| 备份范围 | 已核对完整工作区备份包含 `writingReviews`；资料库备份不含该字段。 |

Electron 双人筛选流程输出及范围综述结果保存在 `.codex-acceptance/academic-b-20261021/`；界面截图：[学术综述工作台](../../../.codex-acceptance/academic-b-20261021/academic-b-review-workbench-electron.png)。隔离 Electron 配置仅使用模拟题录和模拟 AI JSON，不涉及用户现有浏览器资料。
