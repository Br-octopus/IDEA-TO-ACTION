# 学术 D：引用证据核验、审稿回复与投稿准备规格

日期：2026-10-21
上位设计：`docs/superpowers/specs/2026-10-20-writing-domain-expansion-design.md` 第 5—17 节
依赖：共用核心 A/B/C、学术 A/B/C  通过当前阶段验收
状态：实施依据

## 1. 目标与边界

在现有本地写作工作台中提供三个可独立使用的学术任务：

1. 将稿件中的具体论断与文献对应，核对题录并记录支持、部分支持、冲突或证据不足的依据与位置。
2. 逐条管理审稿意见、作者回应和稿件中的实际修改；没有实际修改时，生成修改规划或如实说明不修改的理由。
3. 按用户指定的期刊/学校要求建立投稿清单，关联要求来源、版本和逐项证据，显示未核验项。

本功能是证据台账、可复核任务路线和提示词工作台。它不替用户判断论文真伪或学术质量，不自动确认引用支持关系，不代写或提交稿件，不替代目标期刊的最新说明。用户把审稿内容交给外部模型前，仍需遵守期刊保密规则；应用不自动发送审稿材料。

## 2. 现有能力和复用边界

- 复用 `knowledgeEntries` 中的 `academic-literature` 文献记录、题录来源状态、本人阅读范围、摘录位置与现有 DOI/PMID 单条查询。
- 复用写作基础包管理、提示词复制/带回、写作项目本机保存约定及工作区备份边界。
- 学术 A 已有的论断关系是文献卡片上的简要记录；本阶段增加以“稿件论断”为中心、可对应多条文献的独立核验项目，保留旧字段兼容，不自动覆盖旧记录。
- 学术 B 的综述筛选与提取、学术 C 的论文/章节提示词仍各自维护；本阶段只通过文献库引用它们的已保存结果，不把综述筛选或全文编辑器复制进新界面。

## 3. 项目与数据契约

新增工作区集合 `academicResponseProjects`，每项包含稳定 ID、标题、任务类型、目标期刊/机构、稿件版本标签、文献论断、审稿轮次、目标要求、投稿检查项、提示词/外部结果轮次、保存开关和时间戳。字段均采用白名单清洗；未知键、凭证和绝对本机路径不得进入存储或备份。

### 3.1 引用证据台账

- 一条论断记录包含用户原文、稿件位置、备注和一个或多个来源关联。
- 每个来源关联保存知识库文献 ID、创建时的题录快照、用户标注的引文文本、题录核验状态、论断关系、依据摘录及原文位置。
- 题录状态沿用 `unverified`、`registry-returned`、`user-verified`；登记机构返回只代表其数据库返回记录，不自动代表题录由用户核对。
- 论断关系为 `unassessed`、`supports`、`partially-supports`、`does-not-support`、`contradicts`、`insufficient`。应用只保存用户确认的状态；模型建议单独留作待确认候选。
- 标记“支持/部分支持/不支持/冲突/证据不足”必须记录依据或位置；只看见题名、摘要或摘录时应显式显示阅读范围，不能据此声称核验了全文。
- 覆盖概览统计已关联、待核对、已记录依据和关系冲突的数量，不计算“引用正确率”或“论文质量分”。

### 3.2 审稿意见与逐条回应

- 审稿轮次可标注轮次名、日期、决定和来源；意见逐条保存原文、审稿人/编辑标识、位置、严重程度、回应草稿和解决动作。
- 动作为 `unresolved`、`planned`、`revised` 或 `no-change`。`revised` 必须记录稿件位置和实际改动摘要，并提供修改后摘录或明确的稿件定位；`no-change` 必须记录理由。仅有模型候选或回应文字不能记为已完成修改。
- 汇总回应信只纳入用户勾选的意见，并同时显示实际动作、修改位置、修改依据或不修改理由；未解决与仅计划项继续显式列出。
- 生成审稿回应提示词时标明每条意见是否已有真实修改材料，要求不得虚构实验、分析、结果、页码或改稿动作。
- 审稿人材料默认仅本机保存。复制到外部模型前提示用户确认保密许可；应用不自动上传原意见或稿件。

### 3.3 投稿准备清单

- 项目记录目标期刊/机构、投稿类型、要求版本/生效日期和用户提供的来源。
- 要求卡片保存标题、用户提供的要求原文/摘录、发布机构、适用对象、版本或日期、来源 URL/定位、核对状态和适用性说明。
- 清单项必须能关联某条要求，或显式标为用户自定义；状态为 `todo`、`complete`、`not-applicable`、`blocked`。完成/不适用由用户明确操作并可附证据或理由。
- 未提供目标要求时允许建立空白清单，但所有通用提示都标为待用户核对，不冒称适用于任一期刊。ICMJE 来源卡仅标为医学期刊范围的候选方法来源，目标期刊最新规则优先。
- 完成项数量仅描述用户记录状态，不显示“投稿合规通过”或自动合规结论。

## 4. 提示词和结果版本

- 三类任务分别生成提示词：论断核验、审稿回复、投稿清单核对。
- 提示词只包含本轮用户显式选择的论断、文献题录/摘录、审稿意见、实际改动记录和要求卡片；预览显示材料计数与状态。
- 单份提示词限制 8000 字符，外部结果限制 20000 字符。超限时说明需要缩小选择，不静默删掉来源或截断内容。
- 每次复制或结果带回都保留任务类型、目标、选中记录 ID、提示词文本、创建时间及结果来源状态；不能把模拟输入标成模型实测。
- 外部模型给出的支持关系、改稿建议和投稿判断都先作为候选。只有用户在表单核对后确认，才更新项目状态。

## 5. 基础包与来源

新增学术核验与投稿准备基础包，保存原创任务步骤、提示词骨架、检查项、风险边界和官方来源元数据；不复制受版权保护的指南正文，不将未验证案例写为有效示例。

采用来源及适用边界：

| 来源 | 本包采用内容 | 边界 |
| --- | --- | --- |
| Crossref REST API 文档 | DOI 登记元数据查询入口和题录字段来源说明 | Crossref 返回的是成员/可信来源提交的元数据；不证明论文内容、DOI 未收录不证明论文不存在 |
| ICMJE Recommendations | 医学期刊相关投稿与稿件准备要求的候选来源 | 仅按目标期刊明确采用的范围使用；须由用户核对当前版本及该刊规则 |
| COPE Ethical Guidelines for Peer Reviewers | 审稿保密和审稿伦理边界的来源 | 用于处理审稿材料的谨慎提示，不替代目标期刊具体政策 |
| 目标期刊/学校官方作者指南 | 用户选择的具体版本和要求 | 不预装某刊要求为普遍规则；链接本身不表示应用已读取或核实全部内容 |

核对日期为 2026-10-21。Crossref、ICMJE、COPE 来源卡可标 `source-reviewed` 并记录访问日期；用户选定目标的实际适用性仍需单独确认。包案例保持 `unverified`，直至用真实任务结果逐条复核。

## 6. 持久化、备份和兼容

- `academicResponseProjects` 仅在用户开启项目保存后写入本机；暂停保存沿用当前项目显式保存行为。
- 旧状态迁移时补空集合；完整工作区备份保留该集合，资料库/知识备份排除它。
- 替换、合并、计数、ID 去重、未知字段清理均纳入备份校验。删除项目只影响该项目，不删除知识库文献。
- 关联文献删除或编辑后，项目中的题录快照仍可读；提示文献库当前记录已缺失或与快照不一致。
- 不迁移或重写既有 `claimRelations`，也不改变普通文章、学位论文、综述项目和已有备份的含义。

## 7. 不做事项

- 不从稿件自动抽取全部引文并宣称已核全；用户逐项建立论断或从人工检查结果导入。
- 不把 DOI/PMID 命中、搜索摘要、模型自评或书目相似度当作论断证据。
- 不自动改写完整回应信、论文正文或投稿文件；不代用户提交、上传或联系编辑部。
- 不内置所有期刊模板，不声称适用于未知目标、过期版本或未读取的要求。
- 不把审稿人机密材料自动发给配置模型；本阶段采用本地提示词预览、复制和手动回填。

## 8. 验收路径

1. 新建三种任务项目并保存/暂停；重载后状态可恢复，删除项目不删除文献库记录。
2. 创建一条论断并关联至少两条文献；分别记录支持、冲突、证据不足和未核验项，检查来源位置、摘录与阅读范围。
3. 查询一个 DOI/PMID 并保存登记返回结果，确认它不自动提升题录核验或论断支持状态；显示本地记录与返回题录差异供人工核对。
4. 对一条审稿意见记录真实改动并生成回应；对另一条保留未解决/仅计划状态，不能出现在“已完成改动”的说法中；另验证不修改理由路径。
5. 录入目标期刊要求和来源，逐项标完成/不适用/阻塞；目标要求缺失或未读取时仍显示待核对，不出现自动合规通过。
6. 分别生成三类提示词、复制、带回明确标注为模拟的结果、人工确认候选并检查历史快照；超限时保留原表单和来源。
7. 验证完整备份替换/合并往返、资料库备份排除、本机保存开关、凭证/绝对路径清理和旧状态迁移。
8. 在 D 盘应用中走完引用核验、审稿回复和目标期刊准备路径；检查 390×844、键盘可达、刷新恢复和控制台。真实模型、真机及安装/便携包未验证时分别记录。

## 9. 共用验收映射

本规格落实总蓝图中的来源可追溯、材料范围透明、实际结果复核、未核验边界、提示词版本与备份兼容要求，尤其覆盖 A03、A05、A08、A10—A12、A14—A19、A22、A25。阶段验收记录须逐项注明通过、受限或未验证，不以提示词生成成功替代学术核验。
