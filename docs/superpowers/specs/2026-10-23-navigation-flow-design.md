# 导航与创作流程改造设计（2026-10-23）

## 目标

把现有多个并列入口改成"一条默认流程 + 可从任意阶段单独开始"的混合模式，降低新手上手成本，同时保留老手的直接入口。

## 使用方式

- 默认流程：想法 → 计划 → 研究 → 提示词 → 复盘。
- 允许直接开始的阶段：新建规划（无前置）、社媒研究（只需研究方向）、提示词 Agent（只需任务意图）、文章改写（只需现成文字）。
- 必须从流程进入的阶段：计划工作台（依赖已有计划）、提示词优化（依赖已有提示词或案例上下文）。
- 资产与配置页（提示词库、资料库、设置）保留独立入口，不算创作阶段。

## 导航结构

侧边栏分三组：

1. 开始一件事：新建规划（引导页）。
2. 已有素材直接进来：社媒研究、提示词 Agent、文章改写。
3. 资产与配置：提示词库、资料库、设置。

移动端底部栏：新建、研究、Agent、文章，"更多"弹出资产与配置入口。

面包屑保持"工作台 / 页面名"格式；流程内跳转时附加来源阶段，例如"工作台 / 提示词 Agent / 来自社媒研究"。

## 引导页（新建规划改造）

上半部分为纵向流程条：想法 → 计划 → 研究 → 提示词 → 复盘。每个节点显示未开始 / 进行中 / 已完成状态；点击已完成或进行中的节点跳到对应工作台并带上下文。

流程条下方放 4 张"直接开始"卡片，每张一句话说明适用情况，例如"已经有现成文字想改好 → 文章改写"。

## 阶段间跳转与数据传递

- 想法 → 计划：沿用现有逻辑，保存想法即建计划。
- 计划 → 社媒研究：带入计划目标摘要与研究问题，预填研究任务。
- 研究 → 提示词 Agent：研究结论与选中资料摘要作为参考上下文，复用现有 createPlanFromPromptAgent 的反向通道并新增正向传参。
- Agent → 文章改写：生成的提示词自动存入提示词库，并可在文章改写中选用。
- 任意阶段 → 复盘：沿用各工作台现有复盘入口。
- 数据传递全部使用现有内存态与本地持久化，不新增存储结构。

## 错误与边界

- 跳转目标未就绪时按钮置灰并显示原因，不隐藏按钮。
- 从中间阶段单独开始时，对应工作台顶部也显示流程条，标注"独立任务"；完成后的"下一步"按钮引导回主流程，允许忽略。
- 上下文传递失败（如关联计划被删除）不阻塞进入工作台，仅提示"未找到关联计划，已按独立任务打开"。

## 不改动的部分

- 各工作台内部逻辑、提示词生成与发送安全机制不变。
- 存储结构不变。
