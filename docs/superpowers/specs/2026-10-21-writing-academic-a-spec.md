# 学术 A：文献记录、参考文献库与阅读提示词规格

日期：2026-10-21
上位设计：`2026-10-20-writing-domain-expansion-design.md` 第 9、13–17 节
状态：实施依据

## 1. 目标

在现有本地资料库中提供可检索、可导入/导出的学术文献记录，并让用户按选定文献生成可复制的阅读提示词。文献记录可以从 RIS/BibTeX 子集导入、手动填写，或在用户确认后按 DOI/PMID 查询登记元数据。文献可以继续作为材料选入普通写作工作台。

## 2. 数据与状态

复用 `knowledgeEntries` 和现有 workspace/knowledge-base 备份，不另建数据库或 Zotero 同步系统。学术条目增加严格白名单的书目信息：作者、年份、刊物/出版物、卷期页、DOI、PMID、条目类型、提供方与查询时间，以及用户明确提供的摘要/摘录和摘录位置。保留条目稳定 ID、更新时间、隐藏/选择/来源字段；迁移旧资料时不增加新字段或改变既有默认行为。

下列状态彼此独立：

| 层次 | 状态 | 边界 |
| --- | --- | --- |
| 元数据 | 未核验、注册表返回、用户已核对 | Crossref/NCBI 回传只说明检索到一条登记记录，不等于原文正确或研究质量合格 |
| 阅读范围 | 未读、仅查看题录、仅查看摘要、查看指定摘录、用户确认读过全文 | 导入或查 DOI/PMID 不得自动提升阅读状态；全文状态只能由用户显式选择 |
| 论断关系 | 未评估、支持、不支持、相反、证据不足 | 非“未评估”状态必须关联待核对论断、原文定位和用户记录的依据；题录存在不能证明论断受支持 |

记录用户粘贴或从文件中明确选定的摘要/摘录，单条最多 1200 字；不把网络提供方返回的摘要作为默认内容。完整备份可以保留这些本地记录，但不保留访问令牌、本机路径或完整原文。

## 3. 输入、输出与交互

1. 文献页面提供手工题录录入、RIS/BibTeX（已支持字段子集）导入预览、逐条导入/去重，以及 RIS 导出。
2. DOI/PMID 查询必须由用户主动启动并再次确认。确认界面清楚说明仅发送规范化标识符到 Crossref 或 NCBI；不发送标题、摘要、摘录、正文、项目或本机路径。提供方失败或未找到时保留用户填写内容，不误报成功。
3. 查询只取元数据字段；摘要须由用户主动粘贴/选取。通过提供方返回的元数据一律为“注册表返回”，不自动变成“用户已核对”。
4. 文献列表展示题录来源、元数据状态、用户声明的阅读范围和论断关系状态；可编辑状态并按标题、作者、DOI、PMID、关键词搜索。
5. 用户勾选最多 5 条文献生成阅读提示词。提示词只包含所选题录和用户可见摘录，逐条标明阅读范围与来源，要求模型区分原文信息、推断和待补全文，不得把摘要或题录说成已读全文、不得补造数据或引文。复制仅表示本机复制，不表示模型已收到。
6. 失败、缺字段、重复 DOI、超长摘录和格式不支持都显示具体条目与原因；无效记录不会部分导入。

## 4. 来源与依据

| 来源 | 本阶段采用内容 | 边界 |
| --- | --- | --- |
| Crossref REST API 文档，https://www.crossref.org/documentation/retrieve-metadata/rest-api/，核对日期 2026-10-21 | 按单个 DOI 获取登记元数据；元数据由成员/可信来源提交，允许不完整或错误。只取题录，不拉取摘要 | Crossref 明确部分摘要可能受版权保护；不把摘要复制到应用，也不把登记结果称为原文核验 |

## 5. 不在本阶段

- PDF/Word/OCR 全文解析、全文自动下载、自动抓取引用图谱。
- Zotero/EndNote 云同步、第三方账号、批量 PubMed/Crossref 搜索。
- 自动判断论文质量、自动验证引文是否支持论断，或声称模型已阅读文件。
- 学术综述筛选路线与批次覆盖（学术 B），论文/学位论文结构规划（学术 C），核引/审稿回复/投稿格式（学术 D）。
- 全套 GB/T 7714/APA 自动排版。RIS 导出只做可互操作的题录字段序列化，不能替代目标期刊的格式检查。

## 6. 验收要求

- 旧资料迁移、保存、备份与恢复不丢失，不改变已有资料默认字段。
- 从 RIS 与 BibTeX 导入代表文献，预览、去重、保存、搜索与 RIS 导出后元数据往返可核对。
- DOI 与 PMID 查询只能发送标识符；返回题录来源和时间，状态保持“注册表返回/未核验”；服务失败时表单输入保留。
- 用户能分别更新题录核对、本人阅读范围和论断支持状态；无论来源成功或用户读过全文，都不会自动更改其他状态。
- 阅读提示词只包含勾选记录及其用户可见摘录；没有摘要时明确提示只有题录；不会附带其他资料或全文。
- 刷新与完整工作区备份/恢复保留文献和状态；资料库备份不带写作正文、反馈和文章轮次。
- D 盘 Electron 实际应用完成导入、检索、阅读提示词生成和保存恢复路径；模型服务、真机和安装包未验证时如实记录。
