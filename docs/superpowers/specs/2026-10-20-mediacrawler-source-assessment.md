## 已核对的调用入口

| 目标 | 上游文件与入口 | 裁剪要点 |
| --- | --- | --- |
| 小红书详情 | `media_platform/xhs/client.py`，`get_note_by_id`、`get_note_by_id_from_html` | 保留内容 URL 中的 `xsec_source/xsec_token`；HTML 读取与站点接口调用分别记录来源；每次调用都计入统一预算 |
| 小红书评论 | 同文件，`get_note_comments`、`get_note_all_comments` | 首版只读有限一级评论；不能直接沿用全部评论循环、自动抓二级回复或源内未计量重试 |
| B 站详情 | `media_platform/bilibili/client.py`，`get_video_info` | 接收已有 `bvid/aid`，不附带下载视频或读取所有评论 |
| B 站评论 | 同文件，`get_video_comments`、`get_video_all_comments` | 逐页限量、单次动作和剩余预算双重约束；二级回复默认关闭 |
| 登录与浏览器 | 两平台 `login.py`，`tools/cdp_browser.py` | 独立采集 profile；不得默认与 Electron profile 共用或静默复制 Cookie |

B 站字幕应作为独立来源能力评估，不能因为已引入视频详情客户端就标记支持字幕。当前预研未核实字幕读取入口。

## 不能直接整包调用的原因

`media_platform/xhs/__init__.py` 和 `media_platform/bilibili/__init__.py` 会导入 `core.py`。两平台的 `core.py` 又引用下载器、代理池、存储和应用级配置；B 站还引用 pandas。简单地导入客户端可能先触发整套爬虫依赖。

正式裁剪应使用项目内独立包名和明确的导入边界，保留必要数据解析、有限只读请求与登录功能，移除进入运行路径的整站任务循环、代理池、数据库存储和媒体下载。不能只隐藏界面按钮后仍从包初始化加载整套功能。

## 当前开发机环境核对

2026-10-20 在实际工作树检查到 Node.js 24.14.1、Python 3.11 与 3.14，以及 Chrome 155 和 Edge 155。工作树内尚无专用 Python 虚拟环境。该结果只用于选择下一阶段的开发机预检路径，不代表用户机器已有这些依赖，也不表示本轮创建了环境或运行了采集代码。正式连接管理必须在应用内检查 Python 版本、浏览器可执行文件及专用虚拟环境，并给出可执行的准备与缺失提示。

上游 `pyproject.toml` 声明 Python >= 3.11，依赖列表包含数据库、WebUI、图像及分析包。应用不能直接对该清单执行全量安装；需根据裁剪后的实际导入生成独立锁定依赖，并使用应用专用虚拟环境。小红书客户端还依赖 `xhshow` 签名入口，B 站有独立签名帮助类，均需列入正式导入清单与维护范围。

## 阶段二实施计划必须包含的具体动作

1. 建立 `vendor/mediacrawler` 固定源码、保留许可和 `UPSTREAM.json` 清单，记录文件摘要及本地删改。
2. 提供仅允许平台与能力白名单的本地桥接入口，按行传输 JSON；标准输出只放协议结果，日志走标准错误并脱敏。模型不能提供命令、脚本或浏览器调试地址。
3. Node 管理专用环境、拥有的浏览器与子进程；请求超时和取消都终止本动作，保留已完成结果和累计消耗。
4. 每次底层网络请求、分页和重试均通过同一预算入口，不直接沿用上游不可计量的循环或装饰器重试。
5. 完成环境检查和最小启动/停止入口后，才开放小红书/B 站“读取正文、评论”按钮。结果按需发给报告，正文默认仅内存，用户选择后才保存。

该计划在第一阶段会话与结果契约审查通过后编写和执行。第一阶段不运行 Python、不安装上游依赖，也不把预研副本算成已交付的采集引擎。
