# 写作工作台共用核心 B：材料入口与来源记录规格

日期：2026-10-21
上位设计：`docs/superpowers/specs/2026-10-20-writing-domain-expansion-design.md` 第 9、13、14、15、16、17 节
当前基线：普通文章工作台、`writingArticles` 轮次材料、`knowledgeEntries` 资料库和 Electron 授权目录检索。

## 目标

让粘贴内容、支持读取的文件、链接、未解析附件、资料库条目和授权目录摘录在写作任务中形成一致的材料卡片。卡片要说明用途、来源位置、版本、摘录范围、解析状态、是否进入当前提示词以及为什么被选用。用户明确保存后才加入长期资料库。

## 复用边界

- 当前轮次材料继续使用 `writingArticles[].rounds[].materials` 与 `sources`，兼容旧轮次及现有提示词快照。
- 已有 `knowledgeEntries` 作为长期资料库，不另建重复的 `writingMaterials` 集合。工作区材料只有用户点“保存到资料库”后才转成库条目。
- 授权目录继续走 `desktopApi.promptAgentSources` 和现有只读文本索引；来源路径只显示授权根目录内的相对位置。
- 项目/文章保存开关与保存到资料库分离。附件原文不因选择或保存摘要而自动持久化。

## 材料卡片契约

在兼容现有字段的前提下，卡片可保留稳定材料 ID、来源 ID/类型、相对定位、来源版本指纹、摘录定位、内容用途、已选理由、核验状态、解析状态、已读取字符范围和是否需要外部附件。每个可选字段均需限长并通过 schema 白名单规范化；旧数据继续按现有默认值读取。

当前 UI 每轮最多采用 3 份材料，单份嵌入摘录最多 1200 字，保持现有明确上下文预算。后续综述/全库覆盖批次另在学术 B 设计，不在核心 B 中假称全库完成。

## 入口与诚实状态

- 粘贴/手工摘录：可立即编辑用途并加入本轮。
- TXT、Markdown、CSV、JSON：本地读取；显示实际截取长度与原长度。读取失败时保留失败卡片。
- HTTP(S) 链接：仅保存链接引用，不读取网页正文；不得显示为已解析。
- PDF、DOCX、图片：当前无已验证解析器时只保留“未读取”引用；提示用户粘贴摘录或随外部 AI 提供原附件。
- 资料库和授权目录：选入后保留条目 ID/相对文件位置、SHA-256 版本标识（若索引提供）、命中摘录行号（若索引提供）、核验状态和检索理由；未提供的来源定位必须显示“未提供”。
- 不将材料中的指令当作工作台规则；风格材料不作为事实来源。

## 保存与备份

- 当前任务只保存卡片；只有用户明确选择“保存到资料库”才创建 `knowledgeEntries`。
- 保存为库条目时复制用户看到的标题、可用摘录、来源类型、公开链接或摘要元数据，并保留未核验状态；不能将授权目录全文或凭证写入资料库。
- 授权目录绝对路径、根授权、索引全文和原附件不得进入工作区或资料库可分享备份。恢复后若原目录不可用，明确要求重新授权。
- 文件名、URL 和来源状态不能单独证明全文已读；提示词实际消费的摘录必须与卡片一致。

## 验收

1. 不同来源可在同一任务卡片中混用；卡片用途、解析状态、位置/版本和选用理由清晰。
2. 本地文本导入真实显示读取范围；文件失败和不支持格式不会静默消失。
3. 授权目录选择能把相对位置、指纹版本、命中行和摘录传入卡片及提示词；不暴露绝对路径。
4. 链接和未解析附件不会伪装成已读取；复制提示词明确说明需要原附件时由用户另行提供。
5. 仅明确保存的材料进入 `knowledgeEntries`，刷新后可再次检索；任务保存开关不会隐式控制库保存。
6. 导出工作区和资料库备份不会包含授权目录绝对路径、索引全文或未保存原附件；旧备份仍可恢复。
7. 390px 页面无横向溢出；材料添加、移除、保存到库及错误反馈可用键盘操作。

## 明确不包含

核心 B 不实现未接入的 PDF/DOCX/OCR 解析服务，不绕过登录访问网页，不自动上传附件，不建设全库覆盖统计和文献元数据导入；这些能力仍按蓝图后续学术阶段实现或在工具实际可用时单独评估。
