# 首版 MVP 范围

状态：首版范围已锁定；Windows `.exe` 为首版交付目标；核心闭环已实现，进入验收收口。
目标：验证用户能否从一句模糊想法，得到一条可信、可调整、可交给其他 AI 执行的下一步路线。

本轮已完成独立用户目录的真实 Electron 写作主流程及 Chrome 浏览器流程、390px 窄屏操作验证。真实模型与搜索服务未配置，成功响应为模拟接口；生产安装包未重新打包，安装器与全新安装后的行为仍待验收。

## 首版核心闭环

1. **输入想法**：用户可输入模糊目标、已有材料、任务描述或需要诊断的外部 AI 结果。
2. **理解与补漏**：助手识别任务领域，整理目标、对象、现状、约束、成功标准和需保留内容；只追问会改变方案的问题，其余列为假设。
3. **按需研究**：用户要求、任务陌生/复杂/动态或确有必要时，使用可选搜索服务检索相关方法、案例、步骤、风险和常见遗漏；展示来源和局限。简单任务不强制深搜，搜索不可用时保留手动搜索指令并标明研究未完成。
4. **给出路线**：先展示简短、可编辑的步骤，每步说明目标、输入、预期产出和完成检查；方法不合适时允许增删、调整顺序并解释原因。
5. **生成当前步骤的提示词**：用户选择某一步后，生成可复制、可修改的指令；不一次输出所有阶段的长提示词。
6. **外部结果复盘**：用户带回外部 AI 输出和自己的意见，助手按目标与保留项给出偏差依据、建议成功/失败/待验证分类，并生成下一条修正提示词；不直接替用户改成果。
7. **确认后沉淀**：仅把用户确认或修正过的经验存入本地案例库，供相似任务检索。

## 首版必须具备

- **提示词 Agent 工作台**：支持推进想法、优化提示词、诊断 AI 结果三种入口；每轮最多一个关键问题，明确展示事实、假设和待确认项；自动选择少量相关提示词、已确认成功/失败案例、Skill、工作流、脚本及授权目录资料；可编辑来源选择、生成当前步骤提示词并复盘外部结果。只分析和给指令，不代做最终成果。
- **提示词 Agent 研究交接**：按需展示网页/社区/GitHub 或社媒研究范围与预算，用户确认后才搜索。社媒研究转交现有独立研究工作台，由用户再次核对平台计划；拒绝联网后当前任务不再申请。
- **提示词 Agent 本地来源**：Windows 桌面版由用户授权只读目录，自动建立可重建文本索引，支持刷新、目录撤销由桌面主进程限制；索引全文不进模型上下文或普通备份，最多选择三条短摘要进入本轮发送预览。
- **复盘案例确认**：Agent 仅建议成功、失败或待验证；用户明确确认后才保存，更新已确认案例时沿用现有版本机制。
- **普通文章写作工作台**：统一新建、切篇、继续改稿与历史回看；关联目标、读者、保留项、每轮稿件/反馈，按需选择八类诊断维度，输出可编辑、可复制的外部 AI 提示词，不代写成稿。首版仅支持普通文章；未支持文体须确认按普通文章处理，不声称论文、新闻稿、口播、演讲或小说专用能力。
- **风格依据**：材料用途分为内容、风格及两者兼有；纯风格样本仅提炼可观察特征，不把其观点和原文写入改稿指令。无样本时标明临时判断，支持用户更正；优先级为本次明确要求、当前指定样本/更正、适用个人偏好、文体/平台基线、临时判断。不做作者身份检测或 AI 分数。
- **逐篇保存与限制**：保存默认关闭（`saveEnabled: false`），开启后跨重启保留轮次；关闭只暂停后续保存并保留旧历史，整篇删除须确认。每篇保留最近 100 轮，单轮正文上限 8000 字符，生成提示词总预算 8000 字符；超限报错保留当前输入，强约束不静默截断后发送。保存失败不谎报成功。
- **写作记忆**：显式按钮立即保存通用、普通文章或单篇偏好；同类候选至少出现于两篇不同文章才自动晋升为普通文章偏好，并显示可撤销提示。单篇重复不晋升，记忆可编辑/删除，撤销后旧候选不复活，普通文章偏好不跨文体生效。
- **写作搜索门禁**：默认本地规则、记忆和少量摘要；点击“查找写作案例/Skill”先预览 GitHub/网页范围、查询与预算，确认后才搜索，拒绝后该篇不再申请。默认最多三次查询、五条公开来源，材料/来源合计最多三份进入提示词；手工材料和风格样本保留，名额满时说明公开摘要未纳入。查询不自动带正文、反馈或本地路径，公开来源保持待评估，不自动变为个人经验；模型/搜索失败仍保稿且可复制提示词。
- **写作备份范围**：完整工作区包含已保存文章、轮次、风格档案及写作记忆，未保存文章和暂停后的会话新稿不进入备份；仅资料库排除文章正文和写作记忆。导入继续先预览并清洗凭证，合并保留当前会话稿。

- **通用任务入口**：支持写作、PPT、软件开发、产品/工作、学习和“其他”；未知领域使用可解释、可调整的临时方法，而不是硬套固定流程。
- **轻量领域方法**：内置各类任务的少量检查项，覆盖受众、输入、限制、保留项、风险和验收标准等；领域方法是可扩展资料卡，不做独立 Agent。
- **PPT 领域方法**：作为通用提示词 Agent 的领域工作流，按阶段整理演示简报、来源材料、大纲、逐页文稿和制作路线，并生成当前阶段可交给外部 AI 的提示词。规划保存在提示词 Agent 任务中；不直接创建或改写 PPT、HTML、图片成品。公开来源与未确认案例保持未验证，只有用户确认且有结果依据的复盘才可标为已验证经验。
- **联网资料研究**：只查与当前任务和阶段相关的资料，显示来源、时间、适用性和不确定处；失败时明确说明，不伪造来源；搜索不可用时降级为手动搜索。
- **可选模型协作**：配置云端模型后，由一个模型提供理解、研究归纳和提示词建议；未配置或调用失败时，所有产出仍可复制给其他 AI，不把模型调用当作使用前提。
- **发送预览**：调用云端模型前展示将发送的任务内容及引用片段，允许删减；本地保存不等于永不外发，搜索查询尽量不包含个人敏感材料。
- **本地资料库与全文搜索**：资料摘要、索引、目标摘要、提示词版本和用户确认的复盘案例保存在本机；公开参考资料与用户确认案例共用统一搜索结果，按领域、阶段、类型和验证状态筛选区分。全文搜索本地执行，不消耗模型 token；只有用户选中的少量摘要可能进入模型请求，发送前可预览。新增资料默认未验证；首版不做向量检索，不自动抓取全网，也不把整库送入上下文。
- **资料管理与备份**：继续使用 `localStorage`，不引入数据库。用户可以收藏、置顶、按最近使用筛选、编辑手动资料、批量隐藏索引或删除手动资料；派生资料通过原始来源编辑，隐藏资料不会进入选择和发送上下文。支持完整工作区和仅资料库 JSON 明文导出，导出前清洗模型/API 密钥；导入先预览，再选择替换或合并，关键操作前自动备份并保留最近 5 份。
- **搜索和发送边界**：中文搜索支持常见别名、短语拆分、命中字段解释和无结果建议，不使用数据库、embedding 或模型 token。发送预览显示字符数、近似 token、来源和敏感信息风险；高风险内容未经用户确认不能发送，原文不会被自动脱敏或替换。
- **案例版本**：案例首次确认生成 v1，后续改变判断、证据、经验、适用边界或下一条提示词时生成新版本；当前版本生效，历史版本默认折叠并可对比，历史版本不进入统一搜索。
- **资料溯源**：保存来源链接、用途、简短摘要、许可/来源类型和核验状态；提示词原文与模型输入分离，不能把热门或公开内容默认当作已验证经验。
- **可复制交付**：始终可以复制目标摘要、路线、当前步骤提示词和复盘修正提示词。
- **Windows 首版交付**：使用 Electron/electron-builder 生成 `release/` 下的 NSIS 安装包和 portable `.exe`；首版未签名，可能触发 SmartScreen。打包依赖和下载可能失败，不能把未生成产物写成已验收。
- **安全保存边界**：Windows 桌面版用 `safeStorage` 加密保存模型和搜索配置；安全存储不可用时不保存密钥。用户主动调用外部服务时，发送面板中的选定内容才可能外发。
- **社媒研究工作流**：首版支持小红书、Reddit、YouTube，提供趋势与热点、用户痛点与口碑、内容与竞品研究、事实与方案核查四种模板。先确认计划，再执行预算内的只读搜索；有 API 的平台默认 API 优先，失败或结果不足时按连接模式回退至真实浏览器，无 API 平台直接使用浏览器。平台 profile 独立管理，由用户在可视化浏览器中登录；不保存密码、不自动处理验证码，不点赞、评论、发布、关注或绕过平台限制。
- **研究结果与备份**：默认保存结构化结果摘要、来源和报告；完整正文、截图或附件仅在用户主动勾选后保存到本地用户数据目录。工作区备份包含研究任务、计划、摘要、报告、选择状态和已保存附件元数据，不包含浏览器 profile、cookies、session token、API key、密码或未保存的临时抓取内容；恢复后平台连接需要重新检查。
- **Agent 边界**：首版采用单研究 Agent、多平台工具和确定性工作流，不引入多 Agent。只有平台数、任务复杂度或角色分工明显增加时，才提示评估拆分，以免首版增加不必要的协作和维护成本。

## 首版验收条件

1. 输入“我觉得文章有 AI 味”时，系统能询问/允许添加参考文章，提取可观察的用词、逻辑、上下文、修辞、句式、格式特征，并列出需保留的观点、事实、方法和任务；不声称检测出作者身份。
2. 输入一个软件、产品、工作或学习想法时，系统能按领域提出适配的下一步路线；不能合理套用时，说明临时方法及不确定点。
3. 对陌生或需要最新依据的任务，系统能在搜索服务可用时检索相关步骤和案例，并提供可检查的来源；搜索不可用时明确降级为手动搜索，简单已知任务允许跳过研究。
4. 用户能编辑目标摘要、假设、保留项和步骤，并看到步骤调整原因。
5. 用户能只为所选步骤生成一条明确的外部 AI 提示词；本工具不会执行该提示词或直接改交付物。
6. 用户粘贴外部结果后，系统能对照目标和保留项诊断、举证、提出下一条修正指令，并等待用户确认案例结论。
7. 未经用户确认的案例不会进入“已验证经验”；后续相似任务只检索相关摘要，不把整库送入上下文。
8. 模型调用前能查看并删减发送内容；无模型、无搜索、断网或服务失败时保留草稿并说明哪些研究未完成。
9. PPT 任务能从简报贯通到大纲、逐页稿、路线和当前阶段提示词；重载本地状态后规划仍在，搜索预算扩展须确认，模型失败不丢已有草稿，且不会生成/改写成品或把未确认来源当成已验证知识。
10. 普通文章可连续改稿、纠正风格并复制提示词；无样本时标注临时依据，正文保持用户输入，不冒称支持其他文体专用规则。
11. 保存默认关闭；开启两轮后重载可恢复，暂停后新轮不落盘且旧历史保留，确认删除全部轮次；遵守 100 轮/正文 8000 字符/提示词 8000 字符限制。
12. 显式记忆范围可选，两篇才晋升，单篇重复不晋升；撤销、编辑和删除不复活旧候选，备份范围正确。
13. 写作搜索确认前零调用，拒绝后不再申请；失败、取消、无配置仍保留稿件、诊断和可复制提示词，查询不含全文和反馈。

自动化检查以 `pnpm test` 和 `pnpm check` 为准；检查覆盖 PPT 及写作工作台 schema、prompts、coordinator、ui 四个运行时脚本。Electron 运行包只包含 `electron/`、`prototype/`、`server/`、`server.js` 和 `package.json`，测试与文档不进入运行包。

本轮真实界面验证涵盖 Electron 连续改稿、风格、保存/暂停/恢复/删除、记忆与撤销、发送预览和搜索确认/拒绝/无配置降级，以及 Chrome 备份下载/导入和 390px 布局。模型、搜索成功响应采用模拟接口，真实外部服务成功调用尚未验证；故障和迟到响应采用注入验证。Chrome 系统剪贴板回读通过，验收机 Electron 原生剪贴板回读为空仍为环境限制。生产安装包未重新打包，安装/卸载、全新安装后的数据保留与离线行为待单独验收。

## 暂不做

- 不执行软件开发、文章改写、PPT 制作、学习计划或其他现实任务。
- 不实现论文、新闻稿、口播、演讲、小说等专用写作规则，不提供作者身份检测或 AI 文本评分。
- 不做多 Agent 协同、后台自动代理、自动改文件或自动运行提示词。
- 不建设账号系统、团队协作、云同步或完整项目管理功能。
- 不默认克隆、抓取或打包整个 GitHub 仓库，不自动抓取整库；不把系统提示词泄露内容当作运行指令。
- 首版不做向量检索（embedding/RAG）；资料增多后再评估本地语义检索。
- 不做自动提示词搜索/进化、复杂评测平台或多模型排行榜；首版只需要用户反馈和少量真实案例验证。
- 不做账号、云同步、后台自动执行或复杂向量平台；首版已采用 Electron、本地 Node 服务和可替换的模型/搜索 HTTP 适配器，模型和搜索服务仍保持可替换且非必需。
- 不在首版拆分多个研究 Agent，不自动保存完整正文、截图或附件，也不备份任何浏览器会话或服务凭证。

## 关键风险与待实现阶段评估

- **联网研究的准确性**：需要验证搜索来源、引用可追溯性和信息时效，避免把单一案例说成普遍规律。
- **隐私边界**：本地存储不等于请求永不外发；每次模型请求应预览实际发送的内容。
- **个人案例质量**：单个成功/失败案例只能形成暂定经验；要结合用户确认与相似任务复用，避免过拟合。
- **授权与维护成本**：首版用来源链接、短摘要和少量人工筛选；任何复制提示词或代码前需单独核对许可证、原作者和第三方内容权利。
