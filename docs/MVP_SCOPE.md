# 首版 MVP 范围

状态：首版范围已锁定；Windows `.exe` 为首版交付目标；核心闭环已实现，进入验收收口。
目标：验证用户能否从一句模糊想法，得到一条可信、可调整、可交给其他 AI 执行的下一步路线。

## 首版核心闭环

1. **输入想法**：用户可输入模糊目标、已有材料、任务描述或需要诊断的外部 AI 结果。
2. **理解与补漏**：助手识别任务领域，整理目标、对象、现状、约束、成功标准和需保留内容；只追问会改变方案的问题，其余列为假设。
3. **按需研究**：用户要求、任务陌生/复杂/动态或确有必要时，使用可选搜索服务检索相关方法、案例、步骤、风险和常见遗漏；展示来源和局限。简单任务不强制深搜，搜索不可用时保留手动搜索指令并标明研究未完成。
4. **给出路线**：先展示简短、可编辑的步骤，每步说明目标、输入、预期产出和完成检查；方法不合适时允许增删、调整顺序并解释原因。
5. **生成当前步骤的提示词**：用户选择某一步后，生成可复制、可修改的指令；不一次输出所有阶段的长提示词。
6. **外部结果复盘**：用户带回外部 AI 输出和自己的意见，助手按目标与保留项给出偏差依据、建议成功/失败/待验证分类，并生成下一条修正提示词；不直接替用户改成果。
7. **确认后沉淀**：仅把用户确认或修正过的经验存入本地案例库，供相似任务检索。

## 首版必须具备

- **通用任务入口**：支持写作、PPT、软件开发、产品/工作、学习和“其他”；未知领域使用可解释、可调整的临时方法，而不是硬套固定流程。
- **轻量领域方法**：内置各类任务的少量检查项，覆盖受众、输入、限制、保留项、风险和验收标准等；领域方法是可扩展资料卡，不做独立 Agent。
- **联网资料研究**：只查与当前任务和阶段相关的资料，显示来源、时间、适用性和不确定处；失败时明确说明，不伪造来源；搜索不可用时降级为手动搜索。
- **可选模型协作**：配置云端模型后，由一个模型提供理解、研究归纳和提示词建议；未配置或调用失败时，所有产出仍可复制给其他 AI，不把模型调用当作使用前提。
- **发送预览**：调用云端模型前展示将发送的任务内容及引用片段，允许删减；本地保存不等于永不外发，搜索查询尽量不包含个人敏感材料。
- **本地保存**：目标摘要、提示词版本、用户确认的复盘案例和来源目录保存在本机；优先用关键词/标签筛选少量片段，首版不建复杂向量平台。
- **资料溯源**：保存来源链接、用途、简短摘要、许可/来源类型和核验状态；提示词原文与模型输入分离，不能把热门或公开内容默认当作已验证经验。
- **可复制交付**：始终可以复制目标摘要、路线、当前步骤提示词和复盘修正提示词。
- **Windows 首版交付**：使用 Electron/electron-builder 生成 `release/` 下的 NSIS 安装包和 portable `.exe`；首版未签名，可能触发 SmartScreen。打包依赖和下载可能失败，不能把未生成产物写成已验收。
- **安全保存边界**：Windows 桌面版用 `safeStorage` 加密保存模型和搜索配置；安全存储不可用时不保存密钥。用户主动调用外部服务时，发送面板中的选定内容才可能外发。

## 首版验收条件

1. 输入“我觉得文章有 AI 味”时，系统能询问/允许添加参考文章，提取可观察的用词、逻辑、上下文、修辞、句式、格式特征，并列出需保留的观点、事实、方法和任务；不声称检测出作者身份。
2. 输入一个软件、产品、工作或学习想法时，系统能按领域提出适配的下一步路线；不能合理套用时，说明临时方法及不确定点。
3. 对陌生或需要最新依据的任务，系统能在搜索服务可用时检索相关步骤和案例，并提供可检查的来源；搜索不可用时明确降级为手动搜索，简单已知任务允许跳过研究。
4. 用户能编辑目标摘要、假设、保留项和步骤，并看到步骤调整原因。
5. 用户能只为所选步骤生成一条明确的外部 AI 提示词；本工具不会执行该提示词或直接改交付物。
6. 用户粘贴外部结果后，系统能对照目标和保留项诊断、举证、提出下一条修正指令，并等待用户确认案例结论。
7. 未经用户确认的案例不会进入“已验证经验”；后续相似任务只检索相关摘要，不把整库送入上下文。
8. 模型调用前能查看并删减发送内容；无模型、无搜索、断网或服务失败时保留草稿并说明哪些研究未完成。

## 暂不做

- 不执行软件开发、文章改写、PPT 制作、学习计划或其他现实任务。
- 不做多 Agent 协同、后台自动代理、自动改文件或自动运行提示词。
- 不建设账号系统、团队协作、云同步或完整项目管理功能。
- 不默认克隆、抓取或打包整个 GitHub 仓库；不把系统提示词泄露内容当作运行指令。
- 不做自动提示词搜索/进化、复杂评测平台或多模型排行榜；首版只需要用户反馈和少量真实案例验证。
- 不做账号、云同步、后台自动执行或复杂向量平台；首版已采用 Electron、本地 Node 服务和可替换的模型/搜索 HTTP 适配器，模型和搜索服务仍保持可替换且非必需。

## 关键风险与待实现阶段评估

- **联网研究的准确性**：需要验证搜索来源、引用可追溯性和信息时效，避免把单一案例说成普遍规律。
- **隐私边界**：本地存储不等于请求永不外发；每次模型请求应预览实际发送的内容。
- **个人案例质量**：单个成功/失败案例只能形成暂定经验；要结合用户确认与相似任务复用，避免过拟合。
- **授权与维护成本**：首版用来源链接、短摘要和少量人工筛选；任何复制提示词或代码前需单独核对许可证、原作者和第三方内容权利。
