# 界面设计自查与开源复用依据

核查日期：2026-11-10。范围：用户四组引用、三份设计文档、当前浏览器草图，以及现有插件类型和依赖。当前仍是设计阶段。

## 结论

不能将“七页和 22 条流程可点击”表述成“注释中的功能全部设计并验证完成”。四组要求均已进入文档，但此前真实资料能力、统一工作台、跨板块状态及批注完整生命周期存在缺口。本轮补充规则并修复已复现的草图状态问题；真实格式保真和完整笔迹仍待样本验证。

以下严格区分：设计规则已写明、原型可演示、真实能力已验证。当前没有宣称已验证真实文件解析、网页捕获、模型调用或持久保存。

## 2. Findings：按影响排列

### P1：原资料查看与示例展示尚未闭合

证据：`product-flows.html` 的 `reader()` 根据资料类型返回静态 HTML；不同类型沿用固定目标。资料详情的打开按钮没有传入完整的资料 ID/版本。对话 iframe 显示内容大纲，另一子页显示网站示例，二者未共享真实资料对象。

影响：用户可能以为正在给刚打开的 PPT 批注，提示词却引用网站模板；同一静态示例无法证明 PPT/Word 的版式与文字位置准确。

处理：在工作台第 12 节写明统一查看器、按资料能力显示工具、版本与页标识规则。标记为正式功能前的必验收项，不能用新表单代替真实内容样本。

### P1：用户选择与草稿在重绘后改变——已修复当前草图

复现：在对话填入文字并切到第 2 页 → 资料库 → 工作台，输入变空，页码回到 1；取消第二条批注 → 展开工具，第二条被重新勾选；提示词手工改写 → 切导航 → 返回，改写消失。

处理：`product-flows.js` 在页面替换前保留示例任务输入、页码、预览标签、专注状态、查看滚动位置和手工提示词；按资料类型保留已知批注的选择。新增专注对话和还原入口。批注列表默认收起。该修复只保证当前页面内的示例任务，不代表多任务存储和刷新恢复完成。

### P1：批注列表与修改提示词还缺完整生命周期

证据：`customAnnotation` 只容纳一条新增意见；再次保存覆盖该示例槽位。原型没有完整的编辑、删除撤销、独立保存状态、重新定位、跨资料冲突和提示词依据过期交互。

影响：多条意见可能丢失或指错；生成新提示词可能覆盖手工稿；缺少意见的圈画可能被错误解释。

处理：工作台第 12.3–12.4 节明确每条批注独立 ID、三个独立状态、冲突决定点和“另生成版本”。这些已成为设计验收要求；当前单新增批注演示槽仍不是多批注实现。

### P2：流程评审表单被误当成日常工作入口——已部分纠正

证据：新版草图一度将左侧“新任务”接到多步骤表单，与干净首页和按需询问相冲突。

处理：该按钮现回到输入首页，选项通过示例任务中的弹窗出现。22 条展开流程保留在折叠评审入口；正式短操作使用就地编辑、浮层或抽屉。示例任务目前固定询问受众，真实“是否需要追问”逻辑不在草图中。

### P2：跨板块携带信息和完成后的结果位置未充分演示

证据：多数完成页只返回静态板块；提示词复用示例主要引用标题，未将实际选定正文和版本带入；资料搜索与状态筛选的旧事件各自覆盖行显示；一些撤销/归档/恢复入口仅有说明。

处理：功能流程文档补充交接字段、返回位置、筛选交集、记录状态以及每板块的次级操作。正式结果必须更新对应列表并定位新条目，不能只弹“已保存”。原型仍未承载真实数据列表，保留为待演示项。

### P2：之前的检查范围过于容易被理解为完整验收

22 条流程测试通过 `openFlow(id)` 进入流程，主要验证表单步骤，不覆盖全部真实按钮入口、源数据绑定和模型结果。四种宽度无溢出，也不等同于键盘、触屏或屏幕阅读器验证。

处理：保留原检查，新增实际导航操作的状态保留测试，并在主设计文档标注各自范围。批注类型、定位和转换还需要工作台第 12.5 节列出的真实样本。

## 3. 七板块还需要什么才能认定完整

| 板块 | 设计已补齐的规则 | 原型/能力后续验收重点 |
| --- | --- | --- |
| 工作台 | 单工作台状态、A/C、弹窗、批注生命周期、冲突和旧稿保护 | 同一个真实资料在对话/专注模式中切换；多批注与多个任务不串数据 |
| 资料库 | 不同来源输入、来源状态、版本、引用范围、重复和移除 | 打开所选资料；搜索与筛选同时生效；失败保存输入 |
| 提示词收藏 | 正文/版本/案例/方法卡分离，变量补齐，旧版另存 | 复用实际正文和版本；编辑后列表更新；有效案例有依据 |
| 写作 | 稿件、轮次、规则快照、新稿比较与采用 | 新稿未采用前不替换当前稿；批注能回到该轮原文 |
| 研究 | 来源、筛选理由、计划/执行/结果、回应计划与已改分离 | 取消后保留部分结果；未登录与无结果分别呈现 |
| 记忆与偏好 | 来源、范围、建议确认、停用与撤销 | 全局变化影响清晰；撤销遇到后续修改有冲突提示 |
| 设置 | 已配置与连通分离、备份范围、恢复冲突与收据 | 真实测试请求、实际下载、部分失败与重试不重复写入 |
