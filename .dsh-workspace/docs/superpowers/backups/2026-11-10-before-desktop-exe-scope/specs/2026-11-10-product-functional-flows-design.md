# 全产品功能流程设计 · 第三版

日期：2026-11-10。状态：自查修订版 04，新增细节待评审。配套页面结构见 `2026-11-10-product-interface-redesign.md`；缺口与源码依据见 `2026-11-10-design-audit-and-reuse.md`。

## 设计稿怎么体验

访问 `http://localhost:64289/files/product-flows.html`，切换左侧七个板块。操作页面主按钮，或展开“查看本板块操作流程”。流程页可以填写、上一步、取消、确认和返回；“填入一组示例”可快速体验；本页操作记录可查看已确认内容。

流程页是用于审查步骤的展开视图。正式产品依操作复杂度使用就地编辑、浮层、抽屉或独立页面，不将所有功能改成同一种向导。评审入口、步骤旁说明及状态模拟器不属于正式产品常驻界面。

## 统一交互与数据关系

- 首页仅保留任务输入、添加资料和轻量起点。只有信息缺口影响下一步时才问一个关键问题；已明确的内容不重复询问。
- 简单改名、标签和启停使用就地编辑；短选择使用选区浮层或弹窗；资料详情使用抽屉；正文阅读、版本比较与复杂数据操作使用独立区域。
- 资料是来源，任务引用资料的某个版本或范围；批注关联该范围与修改意见；修改提示词引用选中的批注。收藏保存提示词版本，案例记录实际效果，偏好只表达用户确认的长期要求。
- 全局页切换保留未提交草稿。正式产品显示保存状态，并在永久保存失败时保留输入。当前草图已保留流程表单和单示例任务的对话输入、提示词文本、页码及查看状态；刷新页面会清空，多任务隔离尚未验证。
- 取消处理与删除资料不同；取消保留输入和已保存结果。未提交内容不产生有效版本。失败后重试当前步骤，避免重新填写整条流程。
- 同一时刻有一个明确主动作。复杂选项在对应步骤出现，普通保存不额外增加确认弹窗；恢复、替换和外发才显示实际影响。
- 删除资料先查看引用关系，提供移入回收站或取消。恢复前保留回滚依据，批量操作报告逐项结果；这些次级动作目前是流程规范，尚未接入草图数据。

## 1. 工作台：任务输入与查看内容分开

布局：初始页留白与输入框；开始任务后按需双栏，左侧对话、右侧内容；可切换专注查看，保留草稿、资料页码与缩放。顶部只显示当前资料必要操作。

| 流程 / 入口 | 输入与步骤 | 完成结果与去向 | 取消、失败与限制 |
| --- | --- | --- | --- |
| 新任务 / 输入框、左侧新任务 | 想法 → 按需澄清受众和保留要求 → 核对系统理解 | 进入该任务对话，开始推进 | 已清楚的任务跳过澄清；取消保留想法 |
| 批注整理 / 查看器中的生成修改提示词 | 选意见 → 检查资料版本、原文或区域 → 补充保留项和附件 → 生成 | 独立提示词编辑区；可编辑、复制、回到对应批注 | 定位过期先重新确认；生成失败保留选择；复制时提示附件另行携带 |
| 历史恢复 / 最近任务、历史列表 | 搜索任务 → 看目标、进度和恢复位置 → 继续 | 恢复原任务而非新建同名任务 | 资料缺失提示补充；任务归档后可恢复，不当作删除 |

批注支持文档、PPT、图片、HTML 和网站。文字选区记录原文与上下文；区域批注记录相对位置与截图；网页补充网址、捕获时间和页面版本。工作台看到的是“修改什么、位于哪里、为什么修改”，不是孤立意见。资料变化后显示“待重新定位”，禁止静默套用旧位置。

正式查看器内：选中文字 → 浮层“添加批注” → 写意见/类型 → 保存 → 批注抽屉显示短摘要。工具栏进入批注模式后才展开画笔、框选、箭头、高亮。单击批注返回目标区域；勾选若干条后出现“生成修改提示词”。整页意见无需先框选。

修改提示词结构：资料与版本、逐项定位、修改意图、保留要求、附件清单和验收标准。默认交付提示词，由用户决定如何使用。

## 2. 资料库：找资料、核对来源、带入任务

布局：搜索与筛选在顶部，列表呈现名称、来源、类型、关联任务和批注数；点击打开详情抽屉；阅读进入统一查看器。

| 流程 / 入口 | 输入与步骤 | 完成结果与去向 | 取消、失败与限制 |
| --- | --- | --- | --- |
| 添加资料 / 添加按钮 | 选网页、文件或文本 → 只填写该类型必要字段 → 核对名称、来源、用途与解析状态 | 返回资料库；可继续查看、批注、加入任务 | 获取失败保留链接；文件解析失败可重试；导入成功不自动代表来源可信 |
| 加入任务 / 资料行、详情抽屉 | 选正文范围 → 选任务与用途 → 检查引用 | 工作台资料区出现可追溯引用 | 加入任务不自动发送模型；找不到目标任务保留选择 |

文件预览、网页捕获成功后，正式结果应列出解析页数、遗漏内容和来源状态。识别到重复资料时由用户选择引用现有资料或另存版本。权限受限网页提供导入截图、HTML 或粘贴内容的入口。当前草图展示来源分支与输入校验，未解析真实内容。

## 3. 提示词收藏：正文、版本、案例各有位置

布局：分类与条目列表＋正文详情；版本比较为并排差异视图。案例和方法卡独立子页，保留各自的来源与验证状态。

| 流程 / 入口 | 输入与步骤 | 完成结果与去向 | 取消、失败与限制 |
| --- | --- | --- | --- |
| 新建/修订 / 收藏、编辑副本 | 正文 → 用途、来源与变更说明 → 保存检查 | 新版本进入收藏，旧版本保留 | 编辑应带入当前正文；保存失败保留编辑；不自动标记有效 |
| 复用 / 用于当前任务 | 选提示词 → 填本次背景和变量 → 检查内容 | 工作台生成可编辑草稿 | 不改收藏原文，不自动执行模型请求 |
| 案例 / 记录使用结果 | 关联任务和提示词版本 → 结果、证据、局限 → 核对 | 案例子页记录有效、失败或待验证 | 缺少结果依据时阻止标为有效 |
| 方法卡 / 新建方法 | 名称与场景 → 明确步骤和边界 → 预览 | 方法卡列表，可用于任务 | 不适配当前领域时先提示差异；修改保留版本 |

## 4. 写作：以稿件和轮次为中心

布局：文章列表、稿件正文、轮次侧栏；读稿时隐藏非必要配置。窄屏按文章/正文/轮次切换。文体与专业包独立子页。

| 流程 / 入口 | 输入与步骤 | 完成结果与去向 | 取消、失败与限制 |
| --- | --- | --- | --- |
| 新建文章 / 新建按钮 | 初稿或想法 → 读者、表达目标与保留项 → 创建 | 进入文章工作区 | 没有正文则显示想法，不造出初稿；是否保存历史明确选择 |
| 修改轮次 / 开始下一轮 | 选择依据稿件 → 本轮重点、反馈与保留项 → 核对 | 新轮次及修改提示词，旧稿保留 | 生成提示词不等于已改稿；中断保留本轮输入 |
| 专业包 / 本轮规则预览 | 选包和版本 → 查看规则及保留要求 → 采用 | 固定本轮版本，返回文章 | 新版本从后续轮次采用，不追改旧轮次 |

读稿批注进入同一“选择意见→修改提示词”路径；收到修改后的新稿，再与原稿比较并决定是否采用。专业包配置与稿件正文分开，避免修改文章时误改通用规则。

## 5. 研究：学术看证据，社媒看执行阶段

学术布局：项目选择、证据表、详情抽屉。社媒布局：目标与计划、执行状态、结果列表；未开始时不显示假结果。

| 流程 / 入口 | 输入与步骤 | 完成结果与去向 | 取消、失败与限制 |
| --- | --- | --- | --- |
| 学术项目 / 新建或导入题录 | 研究问题 → RIS/BibTeX 等出处 → 筛选与理由 → 核对 | 项目与证据清单 | 正式导入预览有效、重复和错误条目；未核实来源保留标记 |
| 证据核对 / 文献条目 | 原始出处、原文和页码 → 核实状态、筛选决定与理由 → 核对 | 证据卡返回文献列表 | 摘录与推断分别显示；排除也保留理由 |
| 投稿清单 / 投稿要求 | 目标及要求来源、查阅时间 → 篇幅/格式/材料 → 核对 | 可引用的要求清单 | 区分要求已核实与稿件已满足；不自动投稿 |
| 审稿回应 / 审稿意见 | 原始意见编号 → 回复草稿、修改状态与位置 → 核对 | 逐条回应记录 | 计划与实际完成分开；完成或不修改须写位置/理由 |
| 社媒研究 / 建立计划 | 目标 → 平台、关键词、范围和预算 → 能力与预算确认 | 计划 → 运行 → 结果；可加入资料库或报告提示词 | 未登录、运行中、取消、无结果和失败分别呈现；重试不擅自扩大预算 |

当前草图的社媒流程止于“计划就绪”，不发采集请求；已有结果弹窗仅展示结果条目结构。正式执行结果必须保留链接、平台、时间、摘录和采集状态，不能用示例内容替代。

## 6. 记忆与偏好：自然语言说明影响

布局：已确认偏好列表，范围筛选；待确认建议另区显示。详情包含来源、版本和历史。

| 流程 / 入口 | 输入与步骤 | 完成结果与去向 | 取消、失败与限制 |
| --- | --- | --- | --- |
| 编辑偏好 / 条目、学习建议 | 来源与内容 → 当前任务/领域/全局、启停 → 确认影响 | 新偏好版本，返回列表 | 停用影响后续使用，历史依据保留；未确认建议不自动生效 |

正式列表启停采用直接操作并显示撤销；扩大到全局时说明影响。撤销需预览被还原的版本；后续已有修改时先提示冲突。删除与暂时停用分别提供明确含义。当前可体验编辑与范围确认，历史撤销尚未做成真实数据操作。

## 7. 设置：常用直接改，复杂操作分步检查

布局：通用、模型与连接、备份与恢复、迁移四分类；只展开当前分类。

| 流程 / 入口 | 输入与步骤 | 完成结果与去向 | 取消、失败与限制 |
| --- | --- | --- | --- |
| 连接配置 / 服务设置 | 服务地址 → 保存或测试 → 核对 | 显示已配置、未验证、已验证或失败 | 保存不等于连通；测试失败保留配置；凭证由宿主管理 |
| 备份 / 导出 | 选择内容、附件与偏好 → 预览实际范围 → 导出 | 下载文件和结果记录 | 失败不显示下载成功；不含密钥与登录凭证 |
| 恢复 / 从备份恢复 | 选择文件 → 检查内容和冲突 → 核对合并/替换影响 → 确认 | 按项展示成功、失败、未处理项及恢复前备份 | 冲突未解决阻止继续；确认前取消不改现有数据 |
| 迁移 / 导入旧数据 | 选择来源 → 分类和兼容性 → 确认范围 → 执行 | 迁移收据、遗漏字段与后续处理入口 | 不兼容字段先处理；失败后保留来源和预览 |

## 原型覆盖与后续评审

### 自查补充：跨板块交接的必要内容

| 起点 → 去向 | 必须携带 | 返回与结果 |
| --- | --- | --- |
| 资料库 → 查看器 | 资料 ID、版本、类型、真实内容或转换记录 | 回到原列表和筛选位置；不能固定打开网站示例 |
| 查看器 → 修改提示词 | 选中的批注 ID/版本、资料版本、原文/区域证据、用户意见 | 每项能回到原处；旧稿不被新一轮自动覆盖 |
| 收藏 → 工作台 | 提示词实际正文与版本、变量、适用条件 | 补齐缺项后形成任务副本；不能只带标题 |
| 工作台 → 收藏/案例 | 实际采用的正文版本、来源任务、验证状态 | 保存后列表定位新条目；案例结果与证据另存 |
| 写作/研究 → 工作台 | 当前稿件轮次或所选证据、出处、使用范围 | 指令能回到该稿件/证据；未选资料不混入 |
| 偏好 → 后续任务 | 用户确认的偏好版本和适用范围 | 下一次使用时可解释依据；不重写旧任务历史 |

### 自查补充：各板块次级动作与异常路径

以下是已补写的设计规则，并非全部已有可操作演示。

| 板块 | 次级流程 | 异常/取消/结果 |
| --- | --- | --- |
| 工作台 | 任务更多菜单 → 重命名或归档 → 列表更新；历史筛选 → 查看归档 → 恢复 | 归档保留资料和草稿；名称空白留在编辑；切换任务保存各自输入 |
| 工作台 | 标签关闭 → 选择邻近标签；全部关闭 → 对话；意见编辑 → 保存/丢弃/稍后继续 | 关闭视图不删除源资料；未保存意见显示待续入口 |
| 资料库 | 关键词＋类型＋状态共同筛选 → 结果或无结果 → 清除单个筛选 | 筛选条件取交集，不能各自覆盖；返回详情恢复条件 |
| 资料库 | 检出重复 → 引用原条目/新版本；移除 → 查看引用 → 回收站 → 撤销 | 更新另存资料版本，旧批注保留；已有引用显示缺失而非静默改指向 |
| 收藏 | 版本比较 → 采用旧版为新版本；复用 → 填必需变量 → 预览正文 | 不覆盖旧版；变量缺失指出字段；不把模型自动生成结果标为有效 |
| 收藏 | 方法卡/案例 → 看场景和依据 → 选目标任务 → 带入引用 | 方法卡不是提示词标题；案例不等于通用规则，适用边界随引用保留 |
| 写作 | 收到新稿 → 与本轮依据比较 → 采用/保留待比较 → 下一轮 | 未采用前不替换当前稿；撤销采用回到上一版本；保存失败保留新稿 |
| 写作 | 材料或专业包换版 → 展示变化 → 下轮采用 | 正在进行与历史轮次固定使用原版本，避免规则变化无法解释 |
| 研究 | 题录导入预览 → 有效/重复/错误分组 → 确认可导入项 | 错误条目可修正重试；导入数量与实际列表一致 |
| 研究 | 社媒执行 → 取消/失败/无结果/部分完成 → 选结果 → 保存资料或生成报告提示词 | 取消保留已完成结果并标部分状态；重试先核对剩余预算 |
| 研究 | 审稿意见 → 回复草稿 → 关联实际修改位置 → 用户标已完成 | 计划修改不当成完成；证据不足保留待核实；导出前检查遗漏意见 |
| 偏好 | 待确认建议 → 接受/编辑/忽略；已确认项 → 停用 → 撤销 | 接受时确定范围；忽略不产生有效记忆；撤销遇后续版本先提示冲突 |
| 设置 | 连接测试 → 进行中 → 成功/失败/取消 | 已配置和已验证独立；取消保留输入，不显示连通成功 |
| 设置 | 恢复/迁移执行 → 按项收据 → 查看失败项 → 修正后重试 | 成功项不重复写入；失败与取消不显示全部成功；影响确认使用实际数量 |

简单操作通过列表菜单、就地编辑或短弹窗完成；批注修改与引用详情使用抽屉；涉及整稿阅读和复杂结果的动作才打开独立区域。次级功能不增加首页表单。
