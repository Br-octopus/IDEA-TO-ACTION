# 向前一步

一个帮助用户把模糊想法推进成可执行路线和可复制 AI 指令的个人工具。它负责澄清目标、发现遗漏、按需研究、拆解步骤、生成提示词并复盘外部 AI 的结果；不直接代做文章、PPT、代码或现实任务。

## 当前状态

- 首版交付目标是 Windows 桌面应用：同时提供 NSIS 安装包和 portable `.exe`。
- Electron 桌面壳、本地服务和核心提示词/复盘闭环已完成。本轮已在独立 Electron 用户目录验证写作主流程，并用 Chrome 补充浏览器流程和 390px 窄屏检查；生产安装包未重新打包，安装、卸载和全新安装后的行为仍需验收。
- 已完成 Electron 桌面拆分：`electron/` 管理窗口、内置本地服务和安全设置，`prototype/` 提供静态前端，`server.js` 提供服务入口、模型调用入口和可选搜索适配入口。
- 可编辑发送面板已完成，支持在复制或调用模型前查看和调整实际发送内容。
- 提示词 Agent 已接入独立工作台，支持从模糊想法、现有提示词或不满意的 AI 结果开始，逐阶段梳理、检查遗漏、规划路线、生成当前步骤指令和复盘外部结果。模型请求沿用发送预览；联网搜索先展示范围和预算；社媒资料转交独立研究工作台再次确认。
- 写作工作台统一新建文章和连续改稿：同一篇文章关联目标、读者、保留项、稿件、反馈和轮次，生成可编辑、可复制的诊断与外部 AI 提示词，不直接代写。首版只实现普通文章；论文、新闻稿、口播、演讲、小说等尚无专用规则，需确认按普通文章方式处理。
- 材料可标为内容来源、风格参考或两者兼有；风格样本提炼可观察特征，纯风格样本的观点和原文不进入改稿指令。没有样本时标明临时判断，可更正风格依据。本次明确要求优先于当前样本/更正、适用个人偏好、文体/平台基线和临时判断。
- 文章按篇保存，开关默认关闭（`saveEnabled: false`）；开启后保存历史，关闭只暂停后续保存，已有历史保留，整篇删除须确认。每篇最多保留最近 100 轮，单轮正文上限 8000 字符，生成提示词总预算 8000 字符；超限会报错并保留当前输入，强约束不会静默截断后发送。
- “记住这个偏好”可显式保存通用、普通文章或单篇偏好；同类候选至少有两篇不同文章的证据才自动晋升为普通文章偏好，并提供提示与撤销。单篇重复不晋升，记忆可编辑、删除，普通文章偏好不自动跨文体生效。
- 写作默认使用本地规则、适用记忆和少量本地摘要；“查找写作案例/Skill”先预览 GitHub/网页范围、查询和预算，确认后才搜索。默认最多三次查询、五条公开来源，最多三份材料/来源进入提示词；拒绝后该篇不再申请，搜索失败仍可继续本地诊断和复制提示词。查询不自动带全文、反馈或本地绝对路径，公开结果保持待评估状态。
- PPT 是通用提示词 Agent 按需使用的领域方法，不是独立的 PPT 制作 Agent。它贯通演示简报、大纲、逐页内容初稿、制作路线选择和当前阶段提示词；规划保存在本地工作区，模型/研究失败时保留已有草稿。
- PPT 场景只生成可编辑的内容规划与外部 AI 指令，不创建、改写或导出 PPT、HTML、图片成品；公开资料和案例是待评估线索，只有用户确认且有结果依据的复盘才是已验证经验。
- 提示词 Agent 会从现有提示词库、用户确认的成功/失败案例、方法卡和用户授权的本地资料目录自动挑选最多三条相关摘要。目录只读，不执行仓库脚本；任务摘要、短草稿和来源元数据本地保存，授权目录原路径、索引全文和服务凭证不会进入工作区备份。
- 模型和搜索都是可选能力；未配置、断网、请求失败或模型/搜索服务返回错误时，保持“复制指令/手动搜索”的降级，不会伪称已经调用模型或完成联网研究。
- 公开参考资料只作为待评估的方法和案例线索；用户实际使用后确认的经验作为用户确认案例收录到统一本地资料库，并通过类型和验证状态与公开资料区分。
- 本地资料库保存资料摘要和检索索引，不自动抓取全网；全文搜索在本机完成，不消耗模型 token。只有用户选中的少量摘要可能进入模型请求，发送前可在预览中检查。
- 新增资料默认未验证，收录或热门不代表已验证。当前不使用 embedding/RAG，资料增多后再评估本地语义检索。未来只有同时满足以下门槛才考虑启用：本地资料约 300 条以上且关键词检索明显漏召回；用户持续反馈无结果或结果不相关；存在可接受的本地 embedding 方案和安装包体积；向量在本地生成并保存，不能上传整库；同时保留用户选择范围和摘要上限。在这些门槛满足前，不安装向量数据库或 embedding 依赖。
- 资料和案例增强功能继续使用本地 `localStorage`，当前不引入数据库。资料库支持收藏、置顶、最近使用、手动资料编辑/删除、批量隐藏和来源回溯；从资料库移除只隐藏索引，不删除原始项目、提示词或案例。
- 备份提供普通 JSON 明文两种范围：完整工作区（项目、提示词、案例、资料库、筛选和选择状态，以及已保存文章历史、风格档案与写作记忆）与仅资料库（不含文章正文和写作记忆）。未开启保存的文章和暂停后新增的会话内容不进入备份；合并导入保留当前会话稿。导出会提示可能包含用户内容，但会清洗模型/API 密钥等凭证；导入先预览摘要，再选择替换或合并。导入、替换、合并、清空和大量删除等关键操作前自动备份，并保留最近 5 份。
- 中文搜索使用本地同义词、英文别名和短语拆分，结果显示命中字段，无结果时给出相近词建议；搜索不使用数据库、embedding 或模型 token。模型发送前显示字符数、近似 token、来源分段和敏感信息风险，高风险内容必须由用户确认，不会自动改写原文。
- 案例以当前版本作为生效版本，首次确认为 v1，后续修改结论、证据、经验、边界或下一条提示词形成新版本；历史版本默认折叠，可对比但不会进入统一搜索。
- 社媒研究首版支持小红书、Reddit、YouTube，以及趋势与热点、用户痛点与口碑、内容与竞品研究、事实与方案核查四种模板。支持 API、真实浏览器和自动选择；有 API 的平台默认 API 优先，认证失败、限流、超时、结果不足或字段不全时可回退到浏览器，无 API 的平台可直接使用浏览器。每个平台使用独立 profile，由用户在可视化浏览器登录。
- 社媒研究默认只读，不点赞、评论、发布、关注，也不绕过验证码或平台限制。默认保存结构化摘要和报告；完整正文、截图及附件仅在用户勾选后保存。备份包含研究任务、计划、结果摘要、报告、选择状态和已保存附件元数据，不包含 profile、cookies、session token、API key、密码或未保存的临时内容；恢复后平台状态需重新检查。
- 首版采用单研究 Agent 协调确定性工作流。只有平台数量、任务复杂度或角色分工明显增加时，才提醒评估拆分多 Agent。
- 工具负责澄清目标、规划步骤、生成可复制提示词和复盘外部结果，不直接代做文章、PPT、代码或现实任务。

## 本地运行

```powershell
pnpm check
pnpm start
```

打开 `http://127.0.0.1:4173`。如需连接模型，复制 `.env.example` 的变量到当前终端环境后再运行；真实密钥只放环境变量，不要写入 HTML、`localStorage` 或提交到仓库。当前适配的是 OpenAI 兼容的 `/chat/completions` 接口，搜索服务通过通用 JSON 适配器接入。

## Windows 桌面版

开发模式需要先启动本地服务，再启动 Electron 窗口：

```powershell
pnpm start
# 另开一个终端
pnpm desktop
```

生产构建使用 electron-builder，同时生成 NSIS 安装包和 portable 便携版：

```powershell
pnpm check
pnpm test
pnpm dist:win
```

构建产物位于 `release/`：

- `ForwardStep-<version>-setup.exe`：可选安装目录的 NSIS 安装包，包含开始菜单快捷方式、桌面快捷方式和卸载入口。
- `ForwardStep-<version>-portable.exe`：无需安装的便携版，运行时使用自己的用户数据目录。

生产包会把 Electron 主进程、静态页面和本地 Node 服务一起打进应用，不依赖项目目录、PowerShell、npm 或外部 Node 服务。开发模式仍加载 `http://127.0.0.1:4173`；生产模式由应用自行启动随机端口的内置本地服务。

当前打包限制：`pnpm dist:win` 依赖已安装的项目依赖和 electron-builder；首次构建可能需要下载 Electron/electron-builder 缓存，网络或下载超时会导致本次没有完整产物，不能据此宣称安装包已验收。本轮没有重新生成生产安装包。打包清单只包含运行应用所需的 `electron/`、`prototype/`、`server/`、`server.js` 和 `package.json`；`pnpm check` 覆盖服务端、Electron、提示词 Agent、社媒研究、PPT 场景，以及写作工作台的 schema、prompts、coordinator、ui 四个运行时脚本。`docs/`、`tests/`、`.env` 和用户数据不进入运行包；用户数据由应用运行时保存到用户数据目录。

首版构建未配置代码签名。Windows SmartScreen 可能对安装包或 portable exe 显示“未知发布者”提示，需要用户选择“仍要运行”；正式分发前应使用组织或发行方证书签名。

模型和搜索都是可选能力。未配置服务、网络不可用、请求失败或模型返回错误时，应用仍保留本地编辑、复制指令和手动搜索流程，不会伪称已经完成联网调用。桌面版设置中的模型密钥和搜索密钥使用 Windows `safeStorage` 加密后保存到 Electron 用户数据目录；安全存储不可用时不会保存密钥。

本地保存不等于“永不外发”：只有用户主动发起模型请求时，发送面板中选定的目标摘要、资料摘要或外部结果才可能发送到配置的第三方服务；发送前应检查并删减实际内容。没有模型或搜索服务时，草稿和本地案例仍可继续使用。

## 当前验收边界

`pnpm test`、`pnpm check` 和 `tests/e2e-smoke.test.js` 验证代码、入口、本地服务与主流程边界。本轮另已在真实 Electron 界面验证连续改稿、风格更正、逐篇保存/暂停/恢复/删除、记忆管理和撤销、发送预览、搜索确认/拒绝及无配置降级；Chrome 补充浏览器备份下载/导入与 390px 窄屏操作。存储失败与迟到响应使用注入故障验证，模型与搜索成功路径使用模拟响应，仅证明应用接线，真实外部服务均未配置、未验证成功调用。

Chrome 系统剪贴板回读已通过；当前验收机 Electron 原生剪贴板写入后回读为空，桌面复制仍有环境验证限制。生产安装包未重新打包，安装、卸载、全新安装后的数据保留与离线行为仍需单独验收。每次 `pnpm dist:win` 后，应确认 `release/` 同时存在 NSIS 安装包和 portable `.exe`；下载或构建失败应记录原因，不把缺少产物写成成功。
